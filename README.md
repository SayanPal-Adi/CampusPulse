
# CampusPulse

A college event discovery and management platform developed as a
first-year Computer Science and Engineering project.

## Planned Features

- Browse and search campus events
- Student registration and authentication
- Event creation and management for organizers
- Event registration and capacity management
- Participant lists and attendance tracking
- Organizer analytics dashboard

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python and Flask
- Database: SQLite
- ORM: Flask-SQLAlchemy
- Version Control: Git and GitHub

## Run Locally

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd CampusPulse
```

### 2. Create a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
python run.py
```

Open http://127.0.0.1:5000 in your browser.
